# Context integration contract

- `candybar sync [SAVED_FILE|PROJECT]` reconciles once; `--dry-run --json` previews. `candybar watch [PROJECT|MANIFEST]` uses native events. Only an explicit `--config` selects old enrolled-config compatibility mode.
- Saving `.candybar.toml` or `.candybars/*.candybar.toml` selects all sibling project definitions, retaining nested project identity. Saving plain `candybar.toml` selects that legacy definition only; relative paths retain manifest-directory semantics.
- Directory resolution selects the nearest manifest-bearing project inside the checkout. Git-root activation discovers both formats throughout that bounded checkout, pruning excluded trees. It never walks outside the checkout to discover other repositories. An empty checkout exits before API access (`watch --if-present` quietly).
- LazyVim installs one reload-safe `BufWritePost` hook. It passes the absolute saved path asynchronously to `candybar sync --json`, reports errors, and queues one latest-content follow-up for overlapping saves of the same file. It contains no manifest parsing or API logic.
- Zsh installs one reload-safe project-entry hook. Each shell owns its checkout-scoped watcher, reuses it inside that checkout, and stops it on leaving, entering excluded contexts, or shell exit. It runs no timer or private poller. New shells activate automatically; already-open shells/editors need their integrations reloaded once.
- A manifest-free checkout has no persistent watcher: re-entry activates after manifests appear; an editor save can sync a newly created manifest immediately. Multiple shells may own separate native watchers, but per-endpoint process locking serializes their API reconciliation.
- Register native watches before startup reconciliation, handle atomic replacement/rename and directory creation, and queue events during API work. Native backend failure exits visibly. Removing files preserves registrations and reports known removals within the worker lifetime.
- Project definitions use existing project ownership tags; foreign tags are never overridden. Legacy same-name untagged adoption is permitted only inside selected local context. Migration directory locks and exact ledger IDs remain mandatory; a later rollback/re-cutover requires deliberate ledger reconciliation.
- Reconciliation lock state belongs in the runtime/cache directory, never source control. Existing job lifecycle remains API/operator-owned. New paused jobs still require explicit execution proof and resume outside autosync.
- Retire the centrally enrolled `candybar-watch.service`, not the separate AD-22 `candybar-watchdog.timer`. Keep optional compatibility artifacts explicit; ordinary sync/watch must not load global inventory.
